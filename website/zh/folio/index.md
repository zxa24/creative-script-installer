# Folio：翻译一份版面

Folio 把一份排好版的 InDesign 文档变成另一种语言，不用重新排版。译文回到原来的文本框、样式和页面里。

<!-- diagram: designer exports a zip -> translator works in the web app and saves a zip -> designer imports it -->

1. **设计师导出**：把 InDesign 里的文字导出成一个 `.zip` 文件。
2. **译者翻译**：在网页里翻译，什么都不用装。
3. **设计师导入**：把译文导回来。InDesign 会生成一份翻译后的副本，原文档保持不变。

然后设计师检查结果，需要的话[为新语言调整字体](/zh/folio/fonts)。

## 选择你的部分

- **我负责排版：** [翻译一份版面：给设计师](/zh/folio/designer)，按顺序列出工作的五个阶段。
- **我负责翻译文字：** [在网页里翻译：给译者](/zh/folio/translator)

::: details Folio 不做什么
- 它不会自己翻译。翻译的是人；如果译者需要，网页应用可以用 Google 翻译给出初稿。
- 它不会添加译者没有标注的粗体、斜体或其他格式。
- 它不会改动原文档。
:::
