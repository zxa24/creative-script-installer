# 这套工具是什么

`indesign-toolkit` 是一组出现在 InDesign **脚本面板**里的脚本。每一个都是双击运行的文件。没有插件，没有要停靠的面板，也不会改 InDesign 自己的任何设置。

它们只为一件事而存在：一份文档已经用某种语言排好了版，文字要翻译，而译文要回到**同一个版式** —— 同样的框、同样的样式、同样的页面几何 —— 而不是把文档从头重建。

## 两条轨道

脚本是编号的，第一位数字告诉你在哪条轨道上。

### 轨道 1 — 正常流程

第 `1.x` 组是日常工作按顺序跑的：

| 脚本 | 做什么 |
| --- | --- |
| `1.1 Export Translation Package` | 从打开的文档导出一个翻译包。 |
| `1.2 Import Translation Package` | 把翻译好的包读回该文档的一个副本。 |

这就是完整的正常流程。没出问题的话，你永远不会打开其他组。

分步说明见[正常流程](/zh/guide/workflow)；每个脚本具体写出什么见[第 1 组 — 工作流](/zh/scripts/workflow)。

### 轨道 2 — 需要时才用的工具

第 `2.x`、`3.x`、`4.x` 组**不是**正常流程的一部分。每一次使用都是有意为之：你发现了一个问题，或者想把某样东西从一份文档搬到另一份，于是挑那个对应的工具。

| 组 | 用于 |
| --- | --- |
| [`2.x` 字体与样式](/zh/scripts/type-and-styles) | 新语言需要不同的字体、不同的字重，或者样式表已经蔓延失控。 |
| [`3.x` 检查与修复](/zh/scripts/check-and-repair) | 有东西坏了 —— 溢流文本、缺失链接 —— 或者你想看看改了什么。 |
| [`4.x` 品牌预设](/zh/scripts/brand-presets) | 你调好了一份文档的段落样式，想让姊妹文档跟上。 |

没出问题时跑 `2.x`/`3.x`/`4.x` 的脚本并无害处，但它们也不是例行步骤。有目的地去用。

## 需要什么

- Adobe InDesign，任何较新的版本。安装器会检测机器上每一个已装的版本与语言，并分别装入。
- Adobe Illustrator，可选。安装器也带一小组给它的脚本；没装的话不会提及。
- 别的都不需要。不需要 GitHub 账号、git。粘贴一条命令安装，不需要密码 —— 只有 Illustrator 的首次安装例外，它会问一次。

## 东西落在哪

脚本不会把文件撒得工作目录到处都是。它们只写进文档旁边的一个 `script_outputs/` 目录 —— 翻译包、归档版本、日志、报告。约定及其缘由见[文件与目录](/zh/guide/folders)。
