# 全部脚本

[安装程序](/zh/guide/install)放进 InDesign 和 Illustrator 的每一个脚本，每个附一句用途和讲解它的地方。

编号按种类给 InDesign 脚本分组，不是运行的先后顺序。运行顺序请看[给设计师](/zh/folio/designer)。

## InDesign {#indesign}

在 Scripts 面板的 **User → indesign-toolkit-stable** 下（[在哪里找到脚本](/zh/guide/install#where-to-find-the-scripts)）。

| 脚本 | 用途 | 讲解位置 |
| --- | --- | --- |
| **1.1 Export Translation Package** | 把排好版的文档的文字导出成 zip，交给译者。 | [导出与导入](/zh/folio/export-import#what-to-do) |
| **1.2 Import Translation Package** | 把翻译好的 zip 导回版面的一份副本。 | [导出与导入](/zh/folio/export-import#what-to-do) |
| **2.1 Apply Font Pairing** | 为每种语言选一个配套字体并替换上去。 | [让新语言看起来对](/zh/folio/fonts#apply-font-pairing) |
| **2.2 Apply CJK Styles** | 给中文加上中文的断行和排版设置。 | [让新语言看起来对](/zh/folio/fonts#apply-cjk-styles) |
| **2.3 Set Selection Weight** | 用品牌字体把选中的文字设成某个字重，比如粗体。 | [让新语言看起来对](/zh/folio/fonts#set-selection-weight) |
| **2.4 Reorganize Styles** | 把几百个几乎一样的段落样式换成一小套。 | [导出之前](/zh/folio/before-export#reorganize-styles) |
| **2.5 Repair Cluster GREP** | 让拉丁文单词之间的标点不再显示成中文字体。 | [让新语言看起来对](/zh/folio/fonts#repair-cluster-grep) |
| **2.6 Convert Underline to Rule** | 把中英混排文字下断断续续的下划线换成一条连续的线。 | [让新语言看起来对](/zh/folio/fonts#convert-underline-to-rule) |
| **3.1 Snapshot Before Apply** | 在大改动之前记录版面。和 3.2 配对使用。 | [让新语言看起来对](/zh/folio/fonts#snapshot-before-apply) |
| **3.2 Repair After Apply** | 修复被大改动打乱的地方。和 3.1 配对使用。 | [让新语言看起来对](/zh/folio/fonts#repair-after-apply) |
| **3.3 Relink Missing Links** | 在文档所在文件夹里找回缺失的图片和其他链接。 | [导出之前](/zh/folio/before-export#relink-missing-links) |
| **3.4 Highlight Translation Changes** | 标出上一轮之后文字改了什么。 | [后续轮次](/zh/folio/rounds#highlight-translation-changes) |
| **3.5 Save and Reveal** | 保存文档并打开它所在的文件夹。 | [更多工具](/zh/tools/#save-and-reveal) |
| **4.1 Export Brand Preset** | 把调好的段落样式设置存成一个文件。 | [姊妹文档](/zh/folio/sister-documents#export-brand-preset) |
| **4.2 Apply Brand Preset** | 把这些设置应用到姊妹文档。 | [姊妹文档](/zh/folio/sister-documents#apply-brand-preset) |

## Illustrator {#illustrator}

在菜单 **File → Scripts → illustrator-toolkit-stable**（文件 → 脚本）下。

| 脚本 | 用途 | 讲解位置 |
| --- | --- | --- |
| **Unembed All Images** | 把嵌入的图片变成链接文件，或者清理损坏的链接。 | [更多工具](/zh/tools/#unembed-all-images) |
| **Export Artboard PDFs** | 把每个画板存成单独的 PDF。 | [更多工具](/zh/tools/#export-artboard-pdfs) |
| **Export Small PDF** | 一键导出最小 PDF、最大 PDF、保存并打包。 | [更多工具](/zh/tools/#export-small-pdf) |
| **Replace Fonts** | 在整份文件或选区里把一个字体换成另一个。 | [更多工具](/zh/tools/#replace-fonts) |
| **CJK Composer and Mojikumi** | 为中文或日文设置中日韩书写器、标点挤压和避头尾。 | [更多工具](/zh/tools/#cjk-composer-and-mojikumi) |
